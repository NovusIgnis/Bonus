# Bonus

Useful extras from the work of Fundacja Novus Ignis (Poznań, Poland). Small tools and notes that came out of our daily work with Claude sessions and that others may find handy.

**These are not part of the foundation's mission or of the commitments in its documents.** We share them as they are, because they work for us. Each folder says what it does, what it does not do and what we only observed.

| Folder | What it is |
| --- | --- |
| [`decision-forms/`](decision-forms/) | Claude Code: show the decision form after the full reply, count how often the recommended answer is chosen, keep a backlog of unanswered questions. |
| [`self-compaction/`](self-compaction/) | Claude Code in tmux: a session compacts its own conversation when it decides to, with its own instructions, and then continues by itself. |
| [`time-awareness/`](time-awareness/) | Claude Code: the real date and time with every message and after tool calls, the time since the last exchange, and a header line that shows the hook worked. |

The foundation's main work is at [novusignis.org](https://novusignis.org); its public records are in [OmniActa](https://github.com/NovusIgnis/OmniActa).
